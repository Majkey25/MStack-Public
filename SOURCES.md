MStack packages Code Review's checklists alongside the skill. The motion and Caveman editions carry the guidance they need locally. Grilling can work without delegation. File PR defaults to Draft and checks the user's authorization. Unslop and Ponytail use portable frontmatter.

Modern Web Guidance uses the public catalog or an existing CLI. Design Taste, DevTools, Playwright, Handoff, Incremental Implementation, CI/CD, and Prompt Engineering use shorter instructions that work with the project's own tools.
